# Support

## Where to start

If you are new to the repository, use these files first:

- `README.md` — public overview and quickstart
- `DEPLOYMENT.md` — local and hosted deployment steps
- `CONTRIBUTING.md` — contributor workflow and validation checklist
- `README_STARTUP.md` — startup/demo positioning

## Common help topics

### Running the demo locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

### Running the API locally

```bash
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

### Running tests

```bash
pytest -q
```
